STEP 3 - ENTITY FINDING AGGREGATION
==================================================

For each entity calculate:

- total findings
- findings by rule
- findings by problem type
- findings by severity
- affected cases
- affected assets
- execution-gap count
- negative-space count
- contradiction count
- behaviour-analytics count

Where possible also calculate normalized rates.

Examples:

missing escalation rate =
missing escalation findings /
relevant high/critical cases

missing evidence rate =
missing evidence findings /
investigated serious cases

telemetry blind-spot rate =
affected monitored assets /
total monitored assets

behaviour finding rate =
behaviour findings /
total investigated cases

Do not compare only raw counts because organizations have different
numbers of alerts, cases and assets.

STEP 6 - PREVENT SCORE DISTORTION
==================================================

The scoring system must handle:

- different organization sizes
- duplicate findings
- zero denominators
- missing optional data
- one category producing many repeated findings
- entities with very few cases
- entities with no findings

Use caps/normalization where necessary.

If an entity has no findings, risk should not crash or produce NaN.
