SHADOWWATCH SUPERVISOR APPLICATION
============================================================

Build the professional React frontend that allows a cybersecurity
supervisor/auditor to use the existing ShadowWatch backend.

This is NOT a generic SOC dashboard.

ShadowWatch is a supervisory analytics application.

It helps a supervisor answer:

1. Which organizations require attention?
2. Why does an organization require attention?
3. What operational weaknesses were detected?
4. Which cases should be manually reviewed first?
5. What evidence supports each finding?
6. What should have happened versus what actually happened?
7. How does an organization compare with valid peers?
8. What has a human reviewer confirmed or dismissed?
